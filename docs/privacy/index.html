Zach Prod — Privacy Policy

Last updated: September 6, 2026

Zach Prod runs locally on the user’s computer. Project media and generated videos remain on that computer unless the user explicitly sends a video to a connected third-party service.

TikTok connection data

When a user connects TikTok, access and refresh tokens are stored locally in the Zach Prod application data folder. They are used only to identify the connected account, retrieve permitted account information, and send videos explicitly chosen by the user.

Data sharing

Zach Prod does not sell personal data. TikTok receives only the authorization and publishing information required for the action requested by the user.

Revoking access

A user can disconnect TikTok from the Channels page in Zach Prod. This removes the local connection token.
